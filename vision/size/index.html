Размер пятна

Три квадратика, один другого цвета. Кликни по нему или жми 1, 2, 3 на клавиатуре. Квадратики будут то крупнее, то совсем мелкие, до одного пикселя. Не видишь, выбирай наугад.

Сиди как обычно, когда рисуешь. Ответ быстрый, долго не всматривайся. Около 5 минут, 128 показов. Масштаб браузера 100% (Ctrl+0).

Какой отличается? Клик или 1 / 2 / 3. Не видно, наугад.

Результат

Размер в настоящих пикселях твоего экрана. Меньше этого размера пара для тебя сливается. Пары «линия протана» сдвинуты по линии, вдоль которой путает цвета sero, «синяя ось» сдвинута на столько же поперёк, «яркость» отличается только светлотой. Для обычного глаза пары на «твоей линии» видны уже с 1–2 px.
