How new support agents got trained

  1. Application reviewed, then a voice call to talk through hypothetical situations.
  2. First day: shadow an experienced agent, no tickets yet.
  3. First real ticket, solo — but tagging me to review before closing.
  4. Independent work, with targeted help on whatever edge case came up.

The structure held for over a year and kept running well after I moved on — the server closed some time later, but not because the system broke.
